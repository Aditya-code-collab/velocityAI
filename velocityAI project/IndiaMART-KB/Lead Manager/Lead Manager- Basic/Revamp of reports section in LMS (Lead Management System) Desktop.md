# Revamp of reports section in LMS (Lead Management System) Desktop

Earlier we used to showcase 5 tabs in the reports section as mentioned below to provide insights w.r.t LMS usage and business received from IndiaMART in terms of enquiry received/ BuyLead consumed:Lead Filter: Fetching monthly data for the count of Enquiries and Buyleads consumed for a combination of specific products and locations.Lead Stats: Day and Month Wise Count of Enquiries Received/ Buyleads consumed/ Calls receivedLabels: Count of contacts against assigned labels till particular dateUpcoming reminder: Details of upcoming reminder with CTA redirecting to LMSReply Tracking: Day and Month wise count of replies sent by the userWhat we have done now?Removed two tabs from the old Report section i.e. Labels and Upcoming Reminders. Reason for removing the same are below:As we already have a Reminder page in LMS which provide all the details of past, today's and upcoming reminders so this tab of upcoming reminders was redundant.Also, we found that sellers mainly want the list of contacts against which a particular label is set which is already there in LMS under filter leads so we decided on removing this tab also.We have changed the UI for remaining 3 tabs. Now those 3 tabs are converted into 5 new tabs inPath to view reports:Seller panel >> Lead Manager >> Reports

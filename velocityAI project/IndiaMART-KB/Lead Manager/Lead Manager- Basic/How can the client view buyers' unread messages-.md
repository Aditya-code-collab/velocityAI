# How can the client view buyers' unread messages?

Login the Seller PanelGo to 'Lead Manager' sectionClick on the checkbox 'Unread Messages' Educate the client that using ‘Unread’ icon above the contact list, you can view the list of your unread messages in one go. Once you have selected the ‘Unread’ option, you can also search messages only from the unread ones, with buyer number, mobile number, company name and location which prevents all the unnecessary scrolling to check unread messages.

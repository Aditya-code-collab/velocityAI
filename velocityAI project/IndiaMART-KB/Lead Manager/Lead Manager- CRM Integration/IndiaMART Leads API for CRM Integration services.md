# IndiaMART Leads API for CRM Integration services

The IndiaMART Leads API (also known as IM LMS Leads API / CRM API) enables seamless integration between IndiaMART’s Lead Manager and clients’ external CRM systems. It helps sellers automatically fetch business leads into their CRM for efficient and real-time lead management.Key PurposeStreamlined Lead Management: Automatically sync IndiaMART leads with your CRM.Standardized & Optimized API: Uniform output, URL structure, and error codes.DIY Integration: Designed for self-implementation by CRM teams/vendors.Output Format: JSON format suitable for software systems (not Excel-readable).Eligibility & PricingService Name: IM LMS Leads API (Service ID: 375)Annual Price: ₹10,000 + GST (for paid customers)Complimentary Access: Available by default for Star / Leader sellers.Paid Access: Other paid sellers can subscribe separately.Eligibility Logic:Service ID 375 (purchased) ORCusttype ID 10 / 12 (Star or Leader)Note: Only one variant (Paid or Complimentary) can be active at a time.Types of API ServicesIndiaMART provides two API mechanisms to transfer leads to CRM platforms:Pull APIHow it works: CRM calls IndiaMART at scheduled intervals to fetch leads.Location: Lead Manager → ⋮ (3-dot menu) → Import/Export Leads → Pull APIKey Requirements:Requires a unique Pull API key (visible on the Pull API page + emailed).Time interval between "start" and "end" cannot exceed 7 days.Minimum 5-minute gap between API calls.Cannot fetch leads older than 365 days.API key deactivates if not used for 7 consecutive days.Common Issues & FixesIncorrect Key: Ensure the key in CRM matches the key generated.Old or Expired Key: Regenerate and update the CRM.Wrong Key Type: Pull API requires a Pull API key only.Missing Leads:Review logs on the Pull API page (error reason shown in "Response").Ensure scheduler is not overlapping or running multiple times.Push APIHow it works: IndiaMART sends leads in real time to the CRM’s webhook URL.Location: Lead Manager → ⋮ → Import/Export Leads → Push APIFor CRM Platforms Listed in DropdownActivate Push API directly and share the Webhook Listener URL with your CRM vendor.For Other CRM PlatformsShare the integration guideline document with your vendor.Ask them to generate a valid webhook URL.Submit that URL on the Push API screen.Additional FeaturesLead delivery confirmation via HTTP response status code.Test your webhook listener URL on the Push API screen.Troubleshooting Push APICheck Push API logs for failures.Retry_count column indicates retries made by IndiaMART.Client must fix issues on their CRM side and ensure their webhook is accepting data.Types of Leads TransferredBoth Pull & Push API transfer the following lead types:Enquiries (Direct & ASTBUY)Buy-LeadsPNS

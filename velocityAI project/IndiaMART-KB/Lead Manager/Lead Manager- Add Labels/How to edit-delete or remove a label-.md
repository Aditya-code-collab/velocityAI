# How to edit/delete or remove a label?

Edit/ Delete LabelGuide the steps to change it from Seller dashboard (Seller >> Lead Manager)Ask the client to click on the funnel/Filter icon Edit/ remove the label as per the requirementEdit/ Delete Label for a particular contactEdit: You cannot edit the label for a particular contact. If you wish to make changes in the particular contact then you can edit the label as suggested above (It will be reflected in all the contact where this label is attached) or you can create a new label and add it in that particular contact.Delete/ Remove: Follow the below steps:Guide the steps to change it from Seller dashboard (Seller >> Lead Manager)Select the contact in which you wish to make changesHover on any label which you want to delete.Click on 'x' signThat particular label will be removed from the contact

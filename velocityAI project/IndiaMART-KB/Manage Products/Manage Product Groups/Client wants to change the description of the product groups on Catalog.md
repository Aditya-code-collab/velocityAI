# Client wants to change the description of the product groups on Catalog

Educate the client that to update the description of product groups please follow the below-mentioned path:Seller Panel >> Manage products >> More options >> Manage Groups >> EditWhile updating the description if there is any pre-filled text then ask the client to remove that and mention the new information.Note: In case there is no description provided then our system will auto-generate a description to make visible on the catalog.

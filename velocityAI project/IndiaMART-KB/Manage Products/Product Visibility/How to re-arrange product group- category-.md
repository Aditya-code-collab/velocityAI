# How to re-arrange product group/ category?

Ordering of User-Defined Categories (In all sections like Navigation / Category index page etc)1) Calculate Mcat Rank Weight:For every product find the Mcat Rank for it's prime Mcat according to below:For Rank A, Mcat Rank Weight will be 40For Rank B, Mcat Rank Weight will be 20For Rank C, Mcat Rank Weight will be 10For Rank D, Mcat Rank Weight will be 5For Example: If a product has Mcat Rank A then it’s Product Mcat Rank Weight will be 402) Calculate Quality Score for every category by doing a sum of Mcat Rank Weight & Product Score for all products mapped into it,Suppose in a category there are 5 products having Product Score & various RankProduct-1 (100 product Score) + Rank A(40) = 140Product-2 (80 product Score) + Rank B(20)  = 100Product-3 (90 product Score) + Rank C(10) = 100Product-4 (100 product Score) + Rank A(40) = 140Product-5 (100 product Score) + Rank B(20) = 120Total Quality Score of Category will be 140+100+100+140+120 = 600[ Note : If any product's product score is less than 51 then we have taken product score as half to prioritise in ordering ]3) Order the Category according to the Quality Score of each Category.4) If Quality Score is the same then order the category according to the category sort order defined in the DB.[ Note: UN-grouped Categories (New Items) will always appear at the last position in ordering. ]

# Ticket Tagging Rules

If there is an internal ticket in WIP and we get an external ticket, then a new ticket will be tagged only if the account is paid account The Self ticket can be appended on external(same issue raised on the same day), but external can't be appended on self If conflict team asks to additionally tag ticket in a legal bucket, then the ticket is to be tagged in legal irrespective of the pending days  External Ticket cannot be marked as NAT

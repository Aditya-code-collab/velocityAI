# Call link visible in SMS/ Emails for direct Enquiry to Paid sellers

Till now, we have been directly displaying buyer's number in these type of SMS/ Email.What has been done now?Now, instead of showing the buyer's number directly, we are providing a short URL. Clicking on this short URL opens a blank page in the web browser which in turn opens mobile's dialer having buyer's number. The supplier can then reach a buyer by calling on that number.

# Recommended Products Widget (based on D-rank Mcats) on Seller Dashboard/ Recommended D rank products can be directly added on the seller panel (9th July'19)

What has been done now?We are leveraging the D-rank mcats of a user to show under recommended products section.As the user clicks on the particular card the user is redirected to Add Product Section.Once the product is added the user will be re-directed to the dashboard and we will remove the added product from the recommendation list after displaying it for 5 secs.The user has an option to view that product by clicking on "view product" during the initial 5 secs, if clicked, the user will be re-directed to edit product section While we have added a recommended products section we have removed "Recommend Categories" Section to remove clutter.Please Note: Recommended Products Section will only be visible to the user who has D-rank mcats.

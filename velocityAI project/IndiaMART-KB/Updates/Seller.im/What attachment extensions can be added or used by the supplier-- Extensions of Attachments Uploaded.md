# What attachment extensions can be added or used by the supplier?/ Extensions of Attachments Uploaded by User across IndiaMART (23rd April' 19)

As a part of the security drive, we are restricting extensions of images/docs uploaded by the user across IndiaMARTPurpose Of Restriction: User can upload any executable files from the platform and corrupt the system. Even if we put these changes on each platform, using security tools like burp suite user can bypass front-end checks and upload the file, so we are making these changes in Centralize Image Upload Service.Allowed extensions list:  .jpeg, .jpg, .png, .gif, .doc, .ppt, .pdf, .xlx, .csv, .xlsx, .xlsb, .xlsm, .txt, .bmp, .docx, .pptx, .rtf, .odt, .icoSo If any file doesn't have extension defined in the above list, service will return the failure response with the message "Invalid image extension ...!!!"Scope of these changes:Product ImageUser Profile PicturesCompany LogoEnquiry AttachmentRfq (Images which user attach while posting a BuyLead)Product Related DocsVisiting Card

# Changing Primary mobile verification status of one-year-old verified users/ change in the logic of mobile verification status

Purpose of Changes: Currently, we are not including leads posted by users whose last mobile verification date is older than 1 year in our DNC process. Almost 6% leads, tagged under this category are termed as DNC exclusions. These users should be considered as unverified which will enable OTP verification while posting a BL. This will improve DNC conversion.What has been done:Now, We have started considering the user verification date also at the time of giving mobile verification detailIf Verification date lies within 1 year, user mobile is considered Verified.If Verification date is older than 1 year, user mobile is considered not verified.So that we used to provide details as not verified if mobile user verification date 1-year-old

# BL expiry link / Buyer want to remove or delete the Buy Lead requirement/ Buyers requirement has been fulfilled but still getting emails from other suppliers

Previously :Currently, the buyers receive emails whenever their buy lead is purchased by a supplier. If the buyer's requirement has already been fulfilled from some particular supplier, he/she still keeps on getting the mails for the same requirement when other suppliers purchase it. This can hamper user experience with us.Now:We have now introduced an expiry link in the BL Purchase mailers that provides the buyer the option to remove their requirement once they are satisfied with some supplier. This will help the buyers from not getting any further mails for the same requirement once it has been fulfilled.Earlier:

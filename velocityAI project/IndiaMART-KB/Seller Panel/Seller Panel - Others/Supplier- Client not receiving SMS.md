# Supplier/ Client not receiving SMS

Troubleshooting steps:User needs to check whether the SMS setting is enabled or not.Path:  Seller Panel >> Setting >> Notification settings >> SMS >> enable/disableAsk the user to check his inbox is full or not. He/ she needs to free some space in the inbox then restart the phone.If still the issue is not resolved then mail it to CSD tester with all the required details.

# How to remove Photos and docs from the seller panel?

Currently, the photos and docs which are used in the catalog or shared by the supplier to any user cannot be deleted as per the IndiaMART policy.All other photos and docs which have not been shared by the supplier to a user can be deletedPath:Seller Panel >> Photos & Docs >> Select the file to deleted >> Click on the 3 dots >> Delete >> A pop up will appear >> Click yesThe file will be deleted.PFB the screenshot for reference:

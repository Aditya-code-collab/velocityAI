# The client wants to add Brand Certificate in the catalog

Guide the steps to add it from Seller dashboard:     (Seller >> Company Profile >> Website Pages >> Awards and Achievements)If the client request IndiaMART to make the changes on his/her behalf:- For Contact Center: Ask the client to share the Brand Certificate at "customercare@indiamart.com"- For Servicing: Ask the client to share the Brand Certificate via email and raise a self ticket to make the required changes.

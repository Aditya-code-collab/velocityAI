# How to Change Primary Mobile Number: Paid User

Seller Panel:-The following scenarios can be raised by the client when they want to change the primary mobile number:1. If the client has access to the primary mobile number.2. If the client doesn't have access to the primary mobile number.a: Primary email is not accessible.b: Primary email is accessible.1. If the client has access to the Primary Mobile Number:If the updated mobile number is already registered in another IndiaMART account, the client will receive a message with account details.Choose ‘Yes, continue’, it will disable the other account linked with the same mobile number and update the mobile number in this account.2. If the client doesn't have access to the primary mobile number:Contact Center: Raise a ticket informing the client that we will contact them within 24-48 working hours. Servicing Team: Raise an internal ticket in the "Email/Mobile number change" bucket to get the changes done.Kindly click here to view the prerequisites for raising a ticket.

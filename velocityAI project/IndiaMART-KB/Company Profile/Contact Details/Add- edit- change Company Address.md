# Add/ edit/ change Company Address

Paid Client:Guide the client through the steps to change the information from the Seller Panel:Path: Seller.IM >> Profile >> Primary Details >> Personal DetailsIf the client insists that IndiaMART make the changes on their behalf, ask the client to share their GST certificate to allow the modification.Please note: All documents must come from the registered email ID.For Contact Center: Raise a ticket after receiving the above document.For Servicing Team: Raise a self-ticket and make the required changes to the account.Free Client:Guide the client through the steps to change the information from the Seller Panel:Path: Seller.IM >> Profile >> Primary Details >> Personal DetailsIf the client requests IndiaMART to make the changes on their behalf:Make the required changes on the client’s behalf if the request was received from the registered primary number or primary email.Verify the account information (company name, name on the account) if the call was received from an unknown number.Please NoteWe have frozen edit option on the pin code, city, state & country after GST is marked as verified on Seller Panel.

# How to change primary number: Free Users

Seller Panel:-The following scenarios can be raised by the client when they want to change the primary mobile number:    If the client has access to the primary mobile number.If the client doesn't have access to the primary mobile number but have access to the primary mail ID.If primary mobile number & email ID both are not accessible.1. If the client has access to the Primary Mobile Number:In case the mobile number updated is already registered in another account with IndiaMART, the client will receive the message with account detailsChoose ‘Yes, Continue’, it will disable the other account linked with the same mobile number and update the mobile number in this account.2. If the client doesn't have access to the primary mobile number but have access to the primary mail ID.Need confirmation mail from the existing primary mail id to update the new primary mobile number with mentioned reason why the existing primary mobile number is not accessible to the client along with attached GST certificate.Contact Center: Raise a ticket informing the client that we will contact them within 24-48 working hours. Kindly click here to view the prerequisites for raising a ticket.Servicing Team: Raise an internal ticket in the "Email/Mobile number change" bucket to get the changes done.3. If primary mobile number & email ID both are not accessible.Need confirmation mail from the requested new primary mail id to update new primary mail id and mobile number with mentioned reason why the existing primary mail id and mobile number are not accessible to the client along with attached all the required documents.Contact Center: Raise a ticket informing the client that we will contact them within 24-48 working hours.             Kindly click here to view the prerequisites for raising a ticket.Servicing Team: Raise an internal ticket in the "Email/Mobile number change" bucket to get the changes done.Required documents list are mentioned below: Proprietorship firm: GST is mandate                                                       +

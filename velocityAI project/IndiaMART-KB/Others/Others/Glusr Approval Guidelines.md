# Glusr Approval Guidelines

To approve to freelist (TFL) any Gluser / Company we need below mentioned four mandatory fields: -Company Names E- mail ID (Optional for FCP without Email) Mobile No. Address with city & stateIf any of the above mandatory fields are missing/ invalid then we check the URL/Website (in case of Indian User only) of a company for the required information, and if the required information is not available/ mismatch or URL doesn't work then we mark the Gluser/ company Approved Not to Freelist (NFL).In case the GLUSER does not contain any mobile number & no supporting details are there to update the same, like website, then in such scenario, we will mark the case as DISABLED.All such cases where Primary Mobile no. is already opted should be done in house and the mobile no. should remain updated in an account which is active or having rich data.All such cases where Primary Mobile no. is not present should be marked as disabled with reason “Junk Data”. For Paid users: If anyone of the mandatory fields are missing from paying customer details, then the case will be marked as NFL and a CC ticket will be opened for the same to get updated the required fields on priority. After the required fields has been updated the CC team will have to update the same to Gluser approval team for getting the listing status change

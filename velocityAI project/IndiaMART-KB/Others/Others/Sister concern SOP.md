# Sister concern SOP

Sister Concern Marking Process:1) The process works on the primary condition of GST being verified for the concerned GL IDs2) If the GST is verified, the process checks PAN number which is part of GST and marks all the GL IDs having same PAN number as Parent or Child based on the Cust type3) Further, Child is marked as Sister Concern if the 13th Character of GST number is different from the parent For example,

# How to add/remove negative MCAT?

Sellers can now remove or add negative MCATs as per their needs via the Seller Panel.For Example:If the client is getting irrelevant BuyLead/ AstBuy/ Enquiry from an MCAT in which he is not dealing but has consumed the BuyLeads from the MCAT then the issue could be resolved by the seller himself by marking the MCAT negative from the Seller Panel.Path: Seller Panel >> Settings >> BuyLead Preferences >> Category PreferencesPlease Note: It takes 2-3 days to stop BuyLead/ AstBuy from the negative marked MCATs

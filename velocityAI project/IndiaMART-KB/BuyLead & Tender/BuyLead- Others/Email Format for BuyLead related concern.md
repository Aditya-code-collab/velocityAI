# Email Format for BuyLead related concern

Email reporter needs to share all the details and findings before escalating an issue on the CSD Tester. The issue should be specific and the mail should be elaborative.e.g. “Irrelevant BuyLead” is a vague term. Need to be specific on any issue raised without these details will be directly escalated to the reporter’s HOD.Email Subject: Problem statement + Platform + [Glid: ]e.g.Seller is not able to purchase BuyLeads from Android App (Glid: 28243970)Client not visible on “Jute Bag” MCAT Page (Glid: 28243970)Email Description:Issue: A crisp summary of the raised issue (*Mandatory)Gluser ID: Gluser ID of the affected user/ client (*Mandatory)Platform: Platform or Property where the issue occurred (*Mandatory)(Seller/ DIR-MCAT Page/ DIR-Search page/ Android App/ iOS App/ Email/SMS/App Notification etc.)Ref.

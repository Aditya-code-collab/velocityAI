# BuyLead Allocation if the client is Tempblock

Current ProcessIf a seller has all their dues cleared for a particular service, then they should get the full IMA advantage for that service. Hence, if the client is TEMPBLOCK due to any reason the bellow process will be followed:Once the service is marked TEMPBLOCK, then weekly allocation shall happen as per the higher service running which is not marked TEMPBLOCKIn case of only a single service was there for the client and the client has been temp blocked- 7 weekly allocation (0 for VE starter)Accordingly, update to be done in daily bonus allocation; if only one service was there and it is TEMPBLOCK, then no daily bonus will be allocatedExport and India services will be considered separate accordingly; if IVE is TEMPBLOCK, then export BL allocation will be affected, and if India service is TEMPBLOCK, only India BL allocation will be affectedHow to check?Check the currently running highest service from WebERP

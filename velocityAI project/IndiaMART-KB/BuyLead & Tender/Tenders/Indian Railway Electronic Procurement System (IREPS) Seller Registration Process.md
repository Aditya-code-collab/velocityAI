# Indian Railway Electronic Procurement System (IREPS) Seller Registration Process

Disclaimer: This document is meant for IndiaMART internal use only please do not share any part of this document with the customers.This document can be used as a reference for troubleshooting your client’s problems in the IREPS registration process.The screenshots and steps illustrated in this document are shown as examples only because the government manages the Railway Website. Thus the Tendering steps as well as the UI/UX keep changing.Sellers have to be registered on the IREPS Portal -  https://www.ireps.gov.in/ if they want to bid on the IREPS Tenders they have consumed on IndiaMART.Help Document provided by IREPS - https://www.ireps.gov.in/html/helpdesk/learning_centre.htmlMore more help please check out the FAQs - https://www.ireps.gov.in/ireps/upload/resources/FAQetenders06May10.pdfThe IREPS web application has strict security requirements the prerequisites before getting started are as follows - SoftwareJRE (Java Runtime Environment) Install Java and add https://www.ireps.gov.in/ and https://trial.ireps.gov.in to the security exceptions listToken Driver for Digital Signing Certificate (Provided by supplier of DSC) Vendors / Contractors: Class III with Organization NameYou will need to exporting the Public Key of the Digital CertificateRecombed browser - IE version 10.0 or later (turn off compatibility view and pop-up blocking settings.DocumentsClass 3 Digital Signature Certificate (DSC)GSTAddress ProofPan CardProof of organization MSMEThe step-by-step setup guide has been provided by the ministry - https://www.ireps.gov.in/ireps/upload/resources/Getting_Your_System_Ready_for_IREPS_Application_Version_2.0.pdf (Take help from a computer expert if you need for your initial system step-up).Some of the common symbols/icons used in the IREPS Web application are as follows - Login and start the Registration process-Visit - https://www.ireps.gov.in/epsn/jsp/vendorReg/vendorRegistartionProcess.jspSelect ‘Initiate Registration Request’ to proceedRead the instructions and insert your Pen-drive / USB drive containing the Digital Signing Certificate token before clicking proceed. Then select the certificate of your organization to proceed.Registration process steps-Basic Details - Fill in the basic information of your organization as per the official documents -Note - A firm can get itself registered for the Goods & Services module, Works module, Earning Tenders module, or a combination of any of these. A firm is allowed to participate against tenders pertaining to only those modules for which it is registered. Hence select the types of registrations carefully. Then click ‘Save As Draft’ before proceeding to the next tab.Constitution - Select the type of your business. Here ‘Proprietorship’ is shown as an example -Based on the type of your business you will be required to fill in some additional details. Click ‘Save As Draft’ before proceeding to the next tabApprovals - The user has to choose the registration category and subcategory. If the entity has multiple approvals/registrations, all the approvals can be added one by one.MSE firms are advised to fill up the necessary details in this tab else they may be denied the benefits available under this category like EMD relaxations etc.Statutory - GST detailsPAN DetailsRegistration Details. In Registration Type - Companies should choose Registered with Registrar of Companies , Partnership firms should choose Registrar of Firms option.Upload Document - For the documents that are to be filled up in standard formats (Identification form, Authorization, and Declaration form), the standard format can be downloaded by clicking on the links provided on the page. The process of uploading the documents is as follows -Enter the description of the document to upload then click ‘Select File to Upload’Then click browse to actually upload your file. Now you would need to e-sign the document using the DSC of your organization that you selected before.You will then be able to see the signed document listed as shown below. Click close to upload the next document.Sign & Sumit - After all the outlined steps are completed click on ‘Sign and Submit’    Now you will see the confirmation of registration request submission. Note down the Request ID shown on top of the screen for future reference.Check Registrations Status -The user can check the status of registration at any point in time by Visiting - https://www.ireps.gov.in/epsn/jsp/vendorReg/vendorRegistartionProcess.jspAnd choosing the radio button for the option View Status of my registration request. Here you have to enter your request ID, and click on the Proceed button as shown below.

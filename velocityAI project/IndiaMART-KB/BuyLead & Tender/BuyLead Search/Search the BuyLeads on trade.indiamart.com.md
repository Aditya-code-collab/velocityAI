# Search the BuyLeads on trade.indiamart.com

Step 1: Open “trade.indiamart.com”, and select BuyLeadsStep 2: Searching for a product will show current BuyLeads, with a location filterStep 3: Scroll to the bottom of the page & click on "Show Old BuyLeads from Archive"Step 4: A new page opens up which shows Old/Archived BuyLead and Option to select City/CountryStep 5: Select City to get the result for Old/Archived BuyLeads for the selected city

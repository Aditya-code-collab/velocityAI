# Want BuyLeads from specific countries or continents only

Educate the client that currently there is no provision to choose BuyLeads from specific continents.However, the client can search the leads by entering the country or city as per the requirement under Location Filter.Path:Seller Panel >> Buyleads >> Location Filter >> Enter the country/ place in search bar >> Click on the placeThe client will be able to view the BuyLeads of that location (If available).

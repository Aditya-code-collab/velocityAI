# BuyLead Report

The supplier can check his BuyLead Report under the Manage Products section on seller.indiamart.com.Path:Seller panel >> Manage Products >> Category Report >> BuyLeads ReportThrough this BuyLead Report, the seller can understand their BuyLead consumption pattern with respect to the product categories the seller is dealing with.For paid users, the number of BuyLeads that they have consumed in the last 3 months is shown.For free users, the number of BuyLeads that they have shortlisted in the last 3 months is shown.

# How to create Corporate Email ID?

Check whether the client's catalog is running on own domain or not.Educate the client that e-mail accounts will be configured on "zoho.com" and maximum up to 4 accounts can be created.Ask the client to share details of emails that need to be created in "<xxxx@domainname.com>" format:Contact Center: Raise a ticketServicing Team: Raise an internal ticket in "Pop Account bucket"(Path: WebERP >> STS >> Open Ticket >> Customer Oriented Internal Queries >> Pop Account)Educate the client that the email accounts will be created within 24-48 working hours.

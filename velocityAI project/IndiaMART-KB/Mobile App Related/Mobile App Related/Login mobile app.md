# Login mobile app

Login through Primary mobile numberAsk the client to install the IndiaMART AppClick on get startedEnter the primary mobile numberIt will ask the OTP. Enter the OTP received on the primary mobile number.After number verification, the client will be logged in the mobile app. Login through secondary mobile numberAsk the client to log in through primary number only as he will not be able to view full details if he will log in through secondary mobile number. For example, he will not be able to view BuyLeads and lead manager.Hence, it will not be useful for the client.

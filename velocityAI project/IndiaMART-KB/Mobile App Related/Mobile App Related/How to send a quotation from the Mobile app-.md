# How to send a quotation from the Mobile app?

Now the client can send quotation through Mobile App (Both IOS and Android)IOS and Android Mobile App :Please Note that the path is same for both the apps:Login Mobile App >> Lead Manager >> Select the Contact whom you want to send quotation >> On the left bottom you will view the option of send Quotation (Sign of Rupee) >> click on it >> Fill the Product details >> Click on Next >> Enable Share Payment Link >> Click on next

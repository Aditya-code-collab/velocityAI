# Can two STSs be linked as Parent or sibling with another if their name is same?

No, the common name of two STSs cannot be the ground for marking Parent, Linking or Unlinking of two STSs, cases wherein the servicing/sales team wants to get the same updated then the associate need to get any common detail updated in any of the STS from the client’s end so the DDUP team can entertain the request.

# Prerequisites for raising DDUP ticket

Pre-requisites before raising ticket in DDUP bucketTo Link the STSs (Parent-Child)No need to raise DDUP ticket for Parent-Child linking, profiles with same GST will be automatically marked as Duplicate.If you wish to add Parent-Child linking, please add the valid GST in both parent and child account.To Un-link the STSs (Parent-Child)Parent-Child link will not be removed in below-mentioned condition, so please do raise any ticket if any account falls under below conditions.If the GST of Parent-Child companies are the sameIf the PAN number of both companies are the sameIf anyone of the details (phone+STD, email, mobile) matched with another accountNote: If no relationship found between Parent and child account, we will remove the linkingTo swap the current relation of the STSs (Parent-Child)Swapping cannot be done in below-mentioned conditionsIf the parent account already assigned to some other associate (Not from the same sales hierarchy)If details (Email, Mobile, Phone of the child account not matched with Parent account (only Unlinking is possible)Please NoteEnabling and disabling the account is not a DDUP concern. Kindly do not open ticket for the same in DDUP bucket.For deactivating the services kindly refer to this article.

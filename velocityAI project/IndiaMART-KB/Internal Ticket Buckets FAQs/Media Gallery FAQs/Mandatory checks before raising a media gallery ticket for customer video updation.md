# Mandatory checks before raising a media gallery ticket for customer video updation

Mentioned below are the mandate checks to be performed before raising a media gallery ticket to get the customer video updated:- Before sending the video, Servicing team/CC team must check whether the video is matching with customer details or not.-  All the mandate details i.e. External Ticket ID, Media file details to be updated on an internal ticket.-  Also, get the approval e-mail from the customer saying that shared video belongs to that customer and he/she is allowing IndiaMART to add same on IndiaMART YouTube channel & same should be shared while opening a ticket.-  If video only shows the production process, then it should ideally be added as product video in the Seller Dashboard.

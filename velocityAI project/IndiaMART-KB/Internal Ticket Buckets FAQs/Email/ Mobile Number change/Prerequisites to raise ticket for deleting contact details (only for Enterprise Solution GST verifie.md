# Prerequisites to raise ticket for deleting contact details (only for Enterprise Solution GST verified cases) in Email/mobile number change bucket.

If the profile is GST verified and existing contact details belong to an ex-employee and that person wants to create his own profile by using the same contact details then below process needs to be followed: Please Note: This is applicable only for Enterprise Solution GST verified casesProcess SOP for Contact details deletion:Step 1: Sales/ CC team needs to bring the client's confirmation mail from the existing primary mail id mentioning the reason for deleting contact details.Step 2: Sales/ CC will paste the client's complete mail on the ticket raised in the "Email/ mobile number change" bucket for contact details removal.Step 3: KYC Team will validate the client's mail and remove the contact details as per the client's request

# PNS issue - (Call Connectivity issue/ Number not ringing/ unexpectedly lesser count/no calls)

Mentioned below are the troubleshooting steps:Check if the number is mapped under PNS. If it is not mapped then ask the client to map the same from the settings section for enabling the services.Path: Seller Panel >> Settings >> PNS settingsIf the number is already added but there is no tick mark then kindly tick the checkbox to enable the servicesIf a client wants to add a new number in PNS service.For actual issue identification and validation, the team need to cross-check if this issue raised by the supplier is even matching with our internal data or not. By checking the Queries Tab and PNS Chart [Available data and changes made if any (via GL User history) to be checked at least for last quarter].Path: Company >> Queries >> Click on-call or select PNS in module section to view PNS Queries Servicing team need to probe the seller if all the registered numbers are working fine or not.Check whether the client is receiving calls as per the location preference or not. To know more about PNS call forwarding click here.Please note: Customers with foreign LP do not receive PNS callsIt is mandated for the team to confirm with the client for True Caller blocking if the number is blocked then ask the client to remove the application or to change the handset. Also, make sure that the IM buyer number should not be blocked on sellers' mobile.Check if the number is updated as Seller’s Additional Contact Details, if not then ask the client to update the number in additional contact details by login to the Seller Account. (In case the seller is not getting PNS calls on that specific number).Check if the number is mapped under both Office and Non-Office hours, if not then ask the client to make the changes as per the requirement.If the IVR (auto-answer) is added in the PNS then all the calls will be routed to it. The client will not receive calls on the mobile number (rest numbers)Unable to add landline number -If the landline number is updated as Fax Number then the seller will not be able to add/ map the number to PNS. Ask the seller to remove it.The number should be updated with STS code. If not, then ask the client to update the same (Without prefix ‘0’)

# Prerequisites to raise a ticket for Amount Tagging (Monthly payment mode)

Mentioned below are the prerequisites to be followed in "Monthly Payment mode cases" for amount tagging:The ticket is to be raised if payment is not tagged in 3 days (TAT of 3 days will start from Receipt entry or OVP clearance whichever is later).Additionally, NACH status for respective GL ID in the WebERP should be “Under Process or Activated” (For that NACH documents to be forwarded to NACH team)

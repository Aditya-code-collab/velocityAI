# Prerequisites to raise a "POP Accounts" ticket

Mentioned below are the prerequisites to raise a "POP Accounts" ticket in the internal bucket:- Login URL Link:  Google Apps: “customers-www.gmail.com”  Type of account “webmail.domainname.com” and “mail.domainname.com”,- 2-step verification: Unable to get the code in mobile Server-side solution.- Page loading Issue/Web Browsers' Issue: Screenshot of the login screen if the issue is not fixed even after updating the web browser, clearing the history and cache memory.- Forgot password: Specific ID/IDs to be mentioned, whose password is required.- Email Bounce Cases: Bounced email would be required to analyze.- Not receiving emails: Exchange configuration issue, spamming, emails rejecting, blacklist emails, blacklist IP etc. The requirement of the email id to analyze.- Renaming Email ID: User name of the ID to be renamed and new ID.

# Prerequisites to raise a "Refund Initiation" ticket

Mentioned below are the prerequisites to be followed while raising a "Refund Initiation" ticket in the internal bucket:Detailed reason for the refund is to be mentioned. Payee Details to be provided for “offline payment cases” and for “online payment cases- which are older than 3 months” along with the scanned copy of the cancelled cheque.If the amount asked for refund exceeds the pro-rated amount then respective ZMs approval is to be provided.

# How to check listing of Foreign client/supplier?

Please find below the steps for validating client's listing from "Foreign location"-Install VPN plugin (to browse as a Foreign user) -> Coordinate with your IT person if unable to install                - Install "TunnelBear Free" software from TunnelBear Site -> Will work on any browser                  OR                - Install "Zenmate" for Chrome browser (Reference link)                - Install "AnonymoX" for Firefox browser (Ref. link: Reference link)After installing, open the tool and select any Foreign countryOpen any MCAT/Search page to check the client's listing for Foreign buyersDIR MCAT Pages:For checking listings through Foreign IP we include sellers that have taken Export Package - Diamond > Platinum > Gold > Silver > Starter > Bundled(order of IVE Supplier's listing), If a seller has at least 1 preferred country and is the seller IEC verified and also if the seller has added(Image ,Price and description to the product). Please check the below factors before escalating the issue to CSD Tester / BMP Tester :Check if the seller taken Export Package(Diamond / Platinum / Gold / Silver / Starter / Bundled) : Yes/NoCheck if the seller has marked the country as Not Preferred from where the seller is checking listing - Yes/NoCheck if the mcat has been marked Not Preferred : Yes/NoCheck if the seller has added Image / Price / Description to the product : Yes/NoPrimary Mapping of the Product in the reported Mcat - Yes/NoCheck if the seller is IEC verified - Yes/No(Not Applicable in case of IVE Supplier)Check if the seller has at least 1 Preferred Country - Yes/No(Not Applicable in case of IVE Supplier)Check the Rank of the Mcat - A/B/CLocation Preference of the Seller : Global/India/Local/Hyper-LocalPlease Note : As we are including the Product Quality to the Grid(Image,Price,Description of the Product) , if seller lacks in any of these his/her listing will be shown on lower positions.DIR Search Pages:On Search pages the IVE sellers [Diamond, Platinum, Gold, Silver, Starter] have been prioritized based on MCAT ranks, Dynamic Location Preference [Foreign/Global prioritized], and Preferred Country Behavior.Please check the below factors before escalating the issue to CSD Tester / BMP Tester :Check if the seller has taken Export Package(Diamond / Platinum / Gold / Silver / Starter / Bundled) : Yes/NoCheck if the seller has marked the country as Not Preferred from where the seller is checking listing - Yes/NoCheck if the mcat has been marked Not Preferred : Yes/NoCheck if the seller has added Image / Price / Description to the product : Yes/NoPrimary Mapping of the Product in the reported Mcat - Yes/NoCheck if the seller is IEC verified - Yes/NoCheck the Rank of the Mcat - A/B/CLocation Preference of the Seller : Global/India/Local/Hyper-Local

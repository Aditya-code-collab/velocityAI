# Tester Forum Escalation Matrix (BMP, BL, CSD Tester, Mobitest)

All the client issues related to visibility on DIR, Enquiries and BuyLeads needs to be raised only on CSD-Tester. Direct escalation on BMP-Tester / BL tester must be avoided.If required, then CSD-Tester will loop the concerned forum themselves.The flow of escalating the issue will be as follows:Business Teams >> CSD-TesterIf issue not resolved then -CSD-Tester >> BMP/BL Team (as required)

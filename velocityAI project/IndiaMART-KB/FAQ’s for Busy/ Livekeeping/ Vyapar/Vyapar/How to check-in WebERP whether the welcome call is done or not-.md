# How to check-in WebERP whether the welcome call is done or not?

Search welcome call in the 'History' tab by pressing Ctrl+F5 (Search word- Welcome call)(Path: WebERP >> Open desired company >> History)You'll not find a welcome call in Re-hosting cases (welcome call is not applicable on rehosting cases)After the welcome call update, you'll find that Vyapar service is added for Gl id: xyz (Eligible case- for which the welcome call is done)You can also check the re-hosting status via 'History' tab by pressing Ctrl+F5 (Search word- Rehosting)(Path: WebERP >> Open desired company >> History)

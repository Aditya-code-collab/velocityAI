# FAQs related to C2C/ Contact details

1. Are the users’ personal contact details shared with clients?No, the users’ personal contact details will not be shared with the clients. The clients will only be able to view and contact on the DID numbers (Unique virtual mobile number) which have been assigned to each salesperson.2. What happens if the clients’ calls are not attended?- In case the user fails to attend the clients’ calls, a call escalation process has been implemented wherein the call is further escalated to the users’ senior level.- For instance, if the user receives a call and does not pick it, it will be escalated respective skip manager and in case skip manager also fails to respond to the call, the call finally gets escalated to senior level (The call ends if it is not attended post second escalation). 3. Will the user be able to listen to the call recordings?Yes, the call recordings will be saved in the STS history and the user can revisit the conversation with the client at any point of time so that he captures all the essence of the conversation.4. How can the user view the DID number assigned to him?The user can check the assigned Campaign DID number under Contact Details in WebERP My Profile tab or via Employee Contact Pop-up screen.5. In case of any C2C call related issues and concerns, who shall be the point of contact?Mr. Ashish Singh Parihar shall address all the concerns related to C2C connectivity.6. Is it mandatory to use the C2C feature for all calls?Yes, it is mandatory to use the C2C feature for all calls as the feature has its own benefits. Only in case of special cases like lack of network connectivity, a user might be exempted from the mandate.7. Where can a client find DID details of FSF executive assigned to them?In order to check the DID details of the assigned FSF executive, the client may follow the given steps:Visit Seller Panel / Seller App & click on the ‘Performance Scorecard’.On scrolling down, at the bottom, under ‘Expert Assistance’ the client can view the DID details. 8. What to do if the user’s number is marked as spam on Truecaller?Truecaller spam lists are created by its users. A number gets listed as spam if there are multiple instances of it being listed to make nuisance, marketing or spam calls. If a user’s number has been mistakenly added to Truecaller spam list, please visit the link: https://support.truecaller.com/hc/en-us/requests/new and submit a request for removal of your number from SPAM list.Also, ensure that the teammates and colleagues save the number with correct name & credentials.9. How can a user remove tags on his mobile number within Truecaller?Some irrelevant tags regarding profession or company might be associated with the number. You can remove and edit your tags within the Truecaller app.Android:  1. Open Truecaller  2. Tap Menu button   3. Tap on ‘Edit profile’ at the bottom then tap on the tag to start editing   iPhone: 1. Open Truecaller 2. Tap on the ‘Profile avatar’ in the upper left corner 3. Tap on ‘edit tags’Note: It can take up to 24 hours for the tag to be updated.

# IM Insta FAQ

FAQs:1. What is the 24 hr conversation window?A 24 hr conversation window opens when a buyer sends a WhatsApp message to the seller.When this window is open all the messages that the seller sends to the buyer will be sent to the buyer’s whatsapp along with the Buyer Message Center (present on Desktop, Mobile-site and App), Email and SMS. There is no limit to the number of the messages that the seller can send to the buyer’s WhatsApp during this conversation window.As soon as the buyer sends a message, the 24 hr conversation window opens.2. Can the Seller see the messages if they login into their WhatsApp application on their mobile device with this number? No, if the seller installs a whatsapp application on their phone, they will not be able to login using their PNS number. One number can have only one Whatsapp account, and since there is already a WhatsApp Business API account active on the PNS number, the seller will not be able to login to the WhatsApp application on their phone using this number.All WhatsApp messages sent to the integrated WhatsApp number (in most cases the Seller’s PNS number) will only be shown in the seller’s lead manager.3. What happens if there is already a WhatsApp application active on the PNS number?One number can have only one Whatsapp account. If there is an already registered WhatsApp account on the PNS number, the seller would first have to delete the WhatsApp account on that number and then proceed with the signup for the WhatsApp Integration on Lead Manager. 4. If the seller deletes their WhatsApp account and then signs up for the WhatsApp integration with the same number, will they be able to see the previous chats?No, all the previous WhatsApp chats for that number will be lost even if the seller has done a backup on cloud, once it is integrated with the Lead Manager. This is because we are using the WhatsApp Business API for this integration. Therefore it is advisable to use a fresh number for integration.5. Will the buyer be able to make a whatsapp call to the seller’s API number? WhatsApp doesn’t give any calling option on Buyer’s WhatApp for Chats with API enabled numbers.6.Is it mandatory to use the PNS number for WhatsApp integration?Yes, it’s mandatory. We will do the integration on PNS only.7. How can the seller test the WhatsApp integration?The seller can open their mobile site and click on the WhatsApp button there. Then they will be redirected to the WhatsApp application installed on their phones, they can hit send to the pre-filled message. This way they can send an inquiry. On the Lead Manager they can check whether they have received the WhatsApp message and they can respond to the message to check if the integration is successful or not. Please note that the WhatsApp number used to send the enquiry should be different from the primary number registered for that particular account on IndiaMART.8. Where can the sellers see the WhatsApp enquiries that they have received? The seller can use the filter to view WhatsApp Enquiry. They can all see the data for the WhatsApp enquiry received in the Performance Report from the Lead Manager Menu.9.Is there a way to tell which message was sent from WhatApp by the buyer?Yes, all the messages sent by the buyer from WhatsApp would have a “via WhatsApp” label and a WhatsApp icon beneath them.10. Why is facebook login required during the integration process?Since we are using the WhatsApp Business API for this integration, the process for the procurement of APIs involves logging into the facebook account, creating a facebook business account which then enables the creation of a WhatsApp account using the Cloud API.11.Can the seller use their personal facebook for logging in?Yes, the seller can use their personal facebook account for the WhatsApp integration. The account is only used for the procurement of APIs, no posts or notifications would be sent to or from the facebook account of the seller.12.What are the hygiene checks that we should do for the facebook account?It is preferred if the facebook account should be verified. The account quality should not be compromised, i.e. there should not be any advertising restrictions on the account. This can be checked from this link https://www.facebook.com/accountquality.13. How much time does it take to activate WhatsApp Integration and to start getting enquiries ?After the successful completion of the WhatsApp Integration process, the WhatsApp icon will promptly appear on the Seller’s M-site. As for enquiries, it relies on the buyer’s engagement with the Seller’s IndiaMART page, as buyers are the ones initiating enquiries using the WhatsApp Button on the Seller’s company page on the mobile site.14.

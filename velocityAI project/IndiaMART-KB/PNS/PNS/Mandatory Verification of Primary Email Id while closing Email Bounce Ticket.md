# Mandatory Verification of Primary Email Id while closing Email Bounce Ticket

Previously, a pop-up notification is shown while the closure of any ticket from Cust. Voice Module (External/Self) irrespective of the issue type which mentions “Primary Email Address Not Verified” however that can be bypassed, and ticket can be closed.Now, it is mandatory for the user working on the ticket from Sales or Servicing teams to get the Primary Email Address user verified (Self Verification via OTP) to close pending Email Bounce Ticket on that STS.

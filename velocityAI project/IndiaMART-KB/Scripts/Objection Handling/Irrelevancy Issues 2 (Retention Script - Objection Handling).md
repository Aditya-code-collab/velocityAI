# Irrelevancy Issues 2 (Retention Script - Objection Handling)

Mandatory to ask below mentioned details from client:1. Type of irrelevancy (Detailed description on the irrelevancy being faced)2. Time stamp, from when the client is facing irrelevancy.3. Any changes made by the client or from IndiaMART in seller panel, post which client has started facing irrelevancy issues.4. Also check the details available in the previous tickets, if raised for the same issue.5. Ask or check if client consumes and search the BuyLeads on IM mobile application if yes, educate the client to check for updates and then search for the BuyLeads.BuyLead irrelevancy can be caused by multiple reasons, hence to find out the exact reason in a particular case consultants are supposed to probe below mentioned points until the reason for irrelevancy is found and client is being educated for the future reference:1. BuyLead filters (Preference)2.  Listing’s MCAT Mapping (Decider)3.  BuyLead consumption pattern and Similar BuyLead feature (Decider)4.  Discuss C and D rank MCATs (Decider)5.  Competitor Analysis (Troubleshooting)6.  BLNI (Decider)7.  BuyLeads consumed and Feedback given (Feedback)Preference: Points mentioned as preference just re-arranges or categorizes the BuyLeads shown to the client.Decider: Points mentioned as decider decides the BuyLeads to be shown to the client basis the customization done by the client.Troubleshooting: Point mentioned as troubleshooting are to check if the irrelevancy is because of any technical glitch and the platform being used for BuyLead search are up to date or not?Feedback: Feedback for the consumed BuyLeads shared by the clients are examined on timely basis and help us to improve our system logic used to display BuyLeads to the clients.

# NSD MERP: Make notes while taking call

Now, the employees can make notes while talking to the customer. PFB the details:We have replaced the bottom sheet with a pop-up, which can be minimized into a floating buttonThis notes popup opens automatically when any outgoing call is made from the MERP app. It can also be opened manually by clicking the Call Update icon on My Company / Overview / Search / Hot Leads screen.Users can write notes here, and minimize the popup at any time to browse the rest of the app to see supplier information across different screens.They can then resume writing the notes by expanding the same popup by clicking the floating button.After concluding the call, they can select the appropriate disposition, set a reminder and dispose this call from the popup itself.After a successful call update, the floating button will disappear.

# MERP: How to view query details of the company?

Follow the below steps to view the query details of the company:Login to MERPIt will redirect you to 'Homescreen'Click on 'My Companies'Open the desired company for which you wish to view the details.A company dashboard will appear as belowClick on 'Details'Click on 'Query' to view the detailsQuery tab has to sub-tabs i.e Query Chart and Query Report

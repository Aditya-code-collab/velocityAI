# How can we schedule/ modify/ reschedule or cancel Meeting using CSD Merp App?

Path for scheduling/ adding the appointment: MERP App >> Appointment >> Select the STS for which you want to schedule the appointment >> Call update >> Fill the details; Select call status as Talked and appointment >> Set date (For which the appointment needs to be updated) >> Update callPath for rescheduling the meeting:MERP App >> Appointment >> Select the STS for which you want to reschedule/ cancel the appointment >> Click on Reschedule >> Enter the date and time >> SavePath for Canceling the meeting:MERP App >> Appointment >> Select the STS for which you want to cancel the appointment >> Click on CancelPeople who have access to modify or cancel the scheduled appointment through the CSD Merp App -Tele Account ManagerSales Account ManagerThe person who has generated/ fixed the appointment

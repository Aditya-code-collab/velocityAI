# Severity Policy

This Severity Policy is a guide for Supervisors and Managers to drive compliance and best practices within the organization. This is a program used to address the performance, integrity or behavioral concerns with employees.A “Severity” is given to an employee with the intention to improve the individual’s performance on an ongoing basis for the concerned metrics/ areas.This policy is in effect from 01-11-2020Please click here to view the severity policy.

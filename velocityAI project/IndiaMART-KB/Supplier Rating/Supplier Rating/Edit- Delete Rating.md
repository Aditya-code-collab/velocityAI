# Edit/ Delete Rating

There is no provision to delete the sellers' rating but the buyer can edit the same by following the below steps:Step1: Ask the buyer to login to My.Indiamart.comStep2: Click on MessagesStep3: Select the respective supplier from the contact list for whom the buyer wants to change the ratingThe buyer will be promoted with a rating edit box in the chat window against the submitted rating message.

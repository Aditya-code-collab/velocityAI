# NSD MERP: Focus Segment Visibility option on Android App

We have now the option of visibility & quick filter for focus segment (focus MCATs) in NSD MERP Android App.What has been done now?Focus MCAT name is visible on the company card in My Company screenA quick filter named 'Focus' has been added for one-click access to focus segment companiesBackend architecture is developed in a way that any type of custom label can be shown against any company, and is being used across multiple platforms like NSD-MERP, CSD-MERP, WebERP and Gladmin.
